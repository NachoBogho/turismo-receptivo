# Cuando el viaje cambia de rumbo

Presentación web que se recorre con el scroll. Abrí `index.html` con doble clic: funciona sin internet.

**Controles para presentar:** scroll, o `→` / `↓` / `Espacio` / `Av Pág` para ir a la parada siguiente, `←` / `↑` para volver. Los puntos de la derecha saltan a cada parte y los pines del mapa a cada destino.

`index.html?calma` activa la versión con movimiento reducido. El mapa de la historia está en `docs/storyboard.md`.
